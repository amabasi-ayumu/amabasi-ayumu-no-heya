```html Web開発 基本構造まとめ

Web開発 基本構造まとめ

1. Webシステム全体の構造

ブラウザ
    │
    ▼
index.html
    │
    ├── style.css（見た目）
    │
    ├── app.js（動作）
    │
    └── config.json（設定）
              │
              ▼
            GAS
              │
              ▼
      Googleスプレッドシート

HTMLが中心となり、CSS・JavaScriptを読み込みます。 JavaScriptはJSONやGASと通信します。 GASがスプレッドシートを操作します。

2. CSSとは

CSSは画面の見た目を設定するためのファイルです。

拡張子 

.css

例

style.css
button.css
layout.css
読み込み 
<link rel="stylesheet" href="css/style.css">

3. JavaScriptとは

JavaScriptは画面の動作を担当します。

読み込み 
<script src="js/app.js"></script>

4. JSONとは

JSONは設定データを保存するためのファイルです。

拡張子 
.json
JavaScriptから読み込みます。 
fetch("data/config.json")
    .then(response => response.json())
    .then(data => {

        console.log(data);

    });

5. GASとは

Google Apps Script Googleサービスを操作するサーバー側プログラム

JavaScriptから通信します。 
fetch("https://script.google.com/macros/s/xxxxxxxx/exec")

6. スプレッドシート

GASから操作します。 

const sheet =
SpreadsheetApp
.getActiveSpreadsheet()
.getSheetByName("Data");

7. 呼び出し関係

HTML
│
├── CSS
│
├── JavaScript
│      │
│      ├── JSON
│      │
│      └── GAS
│              │
│              ▼
│      Spreadsheet

8. 各ファイルの役割

ファイル 役割
index.html 画面の土台
style.css 見た目
app.js 動作
config.json 設定データ
GAS サーバー処理
Googleスプレッドシート データ保存

9. 推奨フォルダ構成

Project
│
├── index.html
│
├── css
│   ├── base.css
│   ├── layout.css
│   ├── button.css
│   └── animation.css
│
├── js
│   ├── main.js
│   ├── ui.js
│   ├── json.js
│   ├── gas.js
│   └── event.js
│
├── data
│   └── config.json
│
└── img

10. 基本設計思想

  • HTML：画面の構造
  • CSS：見た目
  • JavaScript：処理・動作
  • JSON：設定・データ
  • GAS：Googleサービスとの通信
  • Spreadsheet：データ保存

それぞれの役割を分離することで、 保守性・拡張性・再利用性が高いシステムになります。

```
