Unity 6: Input System 設定ガイド

Unity 6における新しい「Input System」の導入と基本的な設定方法を解説します。従来のInput Managerからの移行や新規プロジェクトでの利用に役立ててください。

ステップ 1: パッケージのインストール

新しいInput Systemはパッケージとして提供されているため、Package Managerからインストールする必要があります。

  1. Unityエディターの上部メニューから Window > Package Manager を開きます。
  2. 左上のドロップダウンを Packages: Unity Registry に変更します。
  3. 検索窓に Input System と入力します。
  4. リストから「Input System」を選択し、右下の Install ボタンをクリックします。

ステップ 2: 有効化と再起動

インストールが完了すると、バックエンドを切り替えるかどうかの警告ダイアログが表示される場合があります。

注意: 「Yes」をクリックするとエディターが再起動し、新しいInput Systemが有効になります。

手動で設定を変更する場合は以下の手順を踏みます：

  1. Edit > Project Settings を開きます。
  2. 左側のメニューから Player を選択します。
  3. Other Settings を展開します。
  4. 下の方にスクロールし、Active Input Handling を見つけます。
  5. ドロップダウンから Input System Package (New) または Both (新旧両方使う場合) を選択します。
  6. 変更後、エディターを再起動します。

ステップ 3: Input Action アセットの作成

入力を管理するためのアセットを作成します。

  1. Projectウィンドウで右クリックし、Create > Input Actions を選択します。
  2. 作成されたアセットに任意の名前（例: PlayerControls）を付けます。
  3. アセットをダブルクリックして設定ウィンドウを開き、Action Map（例: Player）やAction（例: Move, Jump）を追加・設定します。
  4. 設定が終わったら、ウィンドウ上部の Save Asset をクリックします。

※必要に応じて、Inspectorウィンドウで「Generate C# Class」にチェックを入れ、Applyを押すことでスクリプトから簡単にアクセスできるC#クラスを生成できます。

ステップ 4: スクリプトでの利用例

生成したC#クラスを使った基本的なコード例です。

using UnityEngine;
using UnityEngine.InputSystem;

public class PlayerController : MonoBehaviour
{
    private PlayerControls controls;

    private void Awake()
    {
        // インスタンスの生成
        controls = new PlayerControls();

        // Jumpアクションのコールバック登録
        controls.Player.Jump.performed += ctx => Jump();
    }

    private void OnEnable()
    {
        controls.Enable();
    }

    private void OnDisable()
    {
        controls.Disable();
    }

    private void Update()
    {
        // Moveアクションの入力値を取得
        Vector2 moveInput = controls.Player.Move.ReadValue<Vector2>();
        Debug.Log($"Move Input: {moveInput}");
    }

    private void Jump()
    {
        Debug.Log("Jumped!");
    }
}
